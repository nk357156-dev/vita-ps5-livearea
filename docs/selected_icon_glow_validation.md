# Дорожная карта до первого успешного build

## Этап 1 — каркас проекта

Завершено:
- настройка repo
- skeleton модуля
- runtime config
- заглушки patch API
- пакет docs

## Этап 2 — слой совместимости

Требуется:
- модель профиля прошивки
- flow валидации модуля
- путь stock fallback
- отображение поддерживаемых прошивок

## Этап 3 — анализ shell

Требуется:
- определить путь рендера LiveArea
- определить данные фоновых слоёв и overlay иконок
- определить безопасные точки hook
- зафиксировать различия между вариантами прошивки

## Этап 4 — минимальная кастомная тема

Требуется:
- custom asset pack для фонов и overlay
- простой engine выбора стилей
- test-only UI override
- ветка fallback для неподдерживаемых профилей

## Этап 5 — первый стабильный build

Требования:
- один известный рабочий профиль прошивки
- отсутствие падения shell
- LiveArea остаётся стабильным при навигации
- fallback к stock UI остаётся доступным

## Этап 6 — расширенная поддержка

Только после этапа 5:
- добавить второй профиль прошивки
- расширить поддержку дополнительных классов железа
- поддерживать compatibility matrix актуальной

## Правило

Никакой неподдерживаемый профиль прошивки не должен считаться целью, пока точный shell offset и patch path не были валидированы.
